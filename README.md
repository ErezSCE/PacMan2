# Pacman2

A lightweight, framework‑less Pac‑Man clone built with TypeScript, Vite, and Canvas. The project follows a modular monolith architecture with separate layers for UI, game engine, input handling, audio, asset loading, persistence, and service worker.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm test
```
